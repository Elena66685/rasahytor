# Приложение Прокат НН (управление катком и прокатом)

Данное приложение предназначено для автоматизации работы точки проката спортивного инвентаря и катка.  
Позволяет оформлять заказы, управлять клиентами, отслеживать статус проката, формировать штрих-коды и печатать договоры.

## 📋 Требования перед установкой

- **Java** 17 или новее
- **JavaFX** (в сборке приложения уже должны быть подключены библиотеки)
- **MySQL** 8.0 или новее
- **Maven** (если сборка из исходников)

## 🛠 Технологии

- Java 17
- JavaFX
- MySQL 8
- ZXing (для генерации штрих-кодов)
- iText / pdfbox (для создания PDF-договоров)

## 🚀 Развертывание приложения

### 1. Клонирование репозитория

```bash
git clone https://github.com/your-repo/rosakhutor.git
cd rosakhutor
2. Настройка базы данных
Запустите MySQL сервер.

Выполните дамп базы данных из файла damp2026.sql:mysql -u root -p < damp2026.sqlВ дампе создаётся база rosadb со всеми таблицами (clients, employee, orders, services, role, status и связующая orders_services). 
3.Конфигурация подключения к БД
В корневой папке проекта создайте файл app.properties (рядом с pom.xml или в корне исполняемого JAR).

Пример содержимого app.properties:HOST=localhost
PORT=3306
DB_NAME=rosadb
DB_USER=root
DB_PASS=your_mysql_passwordПараметры читаются классом Consts.java. 
Убедитесь, что файл доступен в classpath.
4. Сборка приложения (Maven)mvn clean package
Исполняемый JAR-файл появится в папке target/.
5. Запуск приложения
java --module-path /path/to/javafx-sdk/lib --add-modules javafx.controls,javafx.fxml -jar target/rosakhutor-1.0-SNAPSHOT.jar
Если JavaFX настроен как зависимость в Maven, можно просто выполнить:java -jar target/rosakhutor-1.0-SNAPSHOT.jar
📁 Структура окружения после развертывания
Папка samples/ – создаётся автоматически для сохранения PDF-договоров.

Папка для штрих-кодов – выбирается пользователем при генерации.

HTML-шаблон договора должен находиться по пути src/main/resources/Договор оказания услуг 2.0.html или в корневой папке приложения.

🔐 Роли и права
Роль	Доступные функции
Продавец	Только просмотр, без создания заказов и товаров
Администратор	Создание заказов, закрытие заказов, отчёты
Старший смены	Управление сотрудниками (интерфейс не до конца реализован)
⚙️ Возможные проблемы и их решение
Ошибка подключения к БД: проверьте, запущен ли MySQL, и верно ли указаны параметры в app.properties.

Не найден HTML шаблон: скопируйте файл договора в папку с JAR или в resources.

Штрих-код не создаётся: убедитесь в наличии прав на запись в выбранную папку.

Некорректный возраст клиента: при добавлении клиента проверяется возраст (не менее 18 лет) и дата не из будущего.
